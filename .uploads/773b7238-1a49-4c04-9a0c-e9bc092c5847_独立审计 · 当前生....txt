IA-01 · 生产解释器的依赖版本落后于安全修复与项目锁定版本 P1
安全 / 运行环境

当前证据：使用生产同一个 Python 3.11 可执行文件查询并导入验证：pypdf 实际为6.21.2，部署清单要求6.21.4；certifi 实际为2026.07.22。检查62个已安装的直接/传递依赖，2个包匹配8个去重后的安全公告（pypdf 7个、certifi 1个）。certifi 的PYSEC与GHSA是同一公告别名，未重复计数。

原因 / 实现边界：CI按清单安装依赖，而现有生产服务使用共享解释器。源码清单升级并不能证明该解释器环境同步升级。pypdf 的实际导入位置位于该Python的Lib/site-packages。

实际影响：PDF附件解析调用PdfReader并遍历页面；已公告的恶意PDF可能造成异常耗时/内存消耗。certifi涉及已撤销信任的emSign根证书，特定攻击条件下影响出站HTTPS信任判断。未实施漏洞利用，没有据此认定已经遭到攻击。

建议：先在独立运行环境安装经过核对的修复版本并完成回归，再在维护窗口切换；把实际运行依赖清单及安全扫描纳入发布验收。不要直接全局升级并假定所有其他程序兼容。

验收标准：生产所用解释器的导入路径、pypdf>=6.21.4、certifi官方修复版（至少2026.10.18）与构建清单一致；重启后核对实际版本，PDF正常解析及出站HTTPS回归通过。

证据：依赖清单与公告匹配 · 实际导入路径 · PDF调用点 app.py:13242 · pypdf官方公告 · certifi官方公告

IA-02 · 公网HTTPS登录响应的会话Cookie缺少Secure属性 P1
安全配置

当前证据：本轮实际GET https://gd2026.top/login，Set-Cookie中的session为HttpOnly、SameSite=Lax，但没有Secure。只保存属性判断，没有保存Cookie值。Nginx配置存在HTTP到HTTPS的301跳转，响应也有HSTS。

原因 / 实现边界：应用SESSION_COOKIE_SECURE默认false，当前生产响应仍采用不安全属性。HTTP跳转与HSTS是缓解措施，不能替代Cookie自身的HTTPS传输限制。

实际影响：在首次HTTP访问、未建立HSTS状态或HTTP入口使用等条件下，浏览器可能通过明文链路发送会话Cookie。不是“当前HTTPS内容未加密”，也不是已经发现会话被盗。

建议：统一公网HTTPS会话配置，并核对代理协议识别。同步检查remember_token；本轮没有登录生产账号，因此没有断言生产remember_token的实际属性。

验收标准：新会话与记住我Cookie均具有适当Secure/HttpOnly/SameSite属性；HTTPS登录、刷新、超时、退出正常，HTTP跳转不造成登录循环。

证据：生产只读HTTP证据 · 应用配置 config.py · Flask安全配置说明

IA-03 · 当前生产启动链没有接入应用的每日自动备份调度 P1
运行保障缺口

当前证据：serve_images.py调用受控boot后直接启动Waitress；受控启动省略backup_sqlite_on_startup，已检查的启动链没有register_backup_jobs/init_notification_scheduler。WMS相关计划任务中未发现专门的数据备份任务。

原因 / 实现边界：恢复入口有意跳过启动维护与外部自动任务，但正常入口的备份调度也没有被独立恢复。配置里AUTO_BACKUP_ENABLED的默认值，不等于运行中有备份任务。

实际影响：无人持续关注时，数据恢复点可能停留在上次人工备份。本机确有当日16:11的production-stopped-before.db文件，5,939,200字节；本轮只核对文件属性，未打开它，不能把文件存在当作恢复可用证明。

建议：将每日备份作为独立、明确可观察的任务接入当前部署入口；不要为了恢复备份而顺带开启微信发送、打印或其他被暂停的自动操作。补充保留周期、失败通知和异机副本。

验收标准：连续两次计划备份按时产生；失败可见；使用合成数据先验证WAL一致性与恢复，再在获准的演练流程验证实际备份。形成明确RPO/RTO，不能只看文件大小。

证据：当前服务入口 · 受控启动代码 · 计划任务快照 · 当日人工备份文件属性 · 本轮备份回归

IA-04 · 已查生产服务入口未配置失败后自动重启 P2
运行保障缺口

当前证据：WMS-Warehouse计划任务RestartCount=0、RestartInterval为空；实际launch.cmd共18行，无goto/循环/timeout重试语句。WMS-Nginx-Heal针对Nginx，不能代替应用进程恢复。

原因 / 实现边界：能够开机启动与能够在进程异常退出后自行恢复是两个不同的能力。目前已查入口没有形成后者的证据。

实际影响：Python进程意外退出后可能需要人工启动，延长两名操作员的停工时间。本轮没有故意终止生产进程，未声称已复现生产停机。外部未登记的看护系统也未作穷尽调查。

建议：在保留数据库单实例租约的前提下，配置有限次数和退避间隔的失败重启，并提供可诊断的健康检查。

验收标准：在隔离服务上模拟异常退出，规定时间内恢复且没有第二实例、重复启动迁移或库存变化；连续失败触发通知而不是无限重启。

证据：任务设置 · 启动脚本结构检查 · 数据库租约入口

IA-05 · 不带版本令牌的旧编辑请求可静默覆盖另一个账号的修改 P2
已复现的协作保护缺口

当前证据：新建合成入库草稿，A、B两个独立仓库账号读取旧页面。A携带令牌保存“A saved”；B不带X-WMS-Document-Revision保存旧内容，返回200，数据库备注变成“B stale overwrite”。相同场景带旧令牌时返回409并保留A的修改。

原因 / 实现边界：services/document_edit_guard.py:124起，not token分支直接调用原视图，保留旧客户端兼容。因此版本校验是可选协议。

实际影响：风险集中于旧页面、旧客户端或其他未接入版本协议的调用方。不能据此说正常现行Web双人编辑保护无效；携带版本令牌的独立场景和相关回归均通过。此次复现修改的是草稿备注，未发现库存因此被改错。

建议：盘点所有编辑消费点，为现有单据写入建立明确的强制版本契约或受限兼容策略；新建、重放和编辑要分别处理，避免直接破坏旧客户端。

验收标准：两个独立账号在所有可编辑单据族中，旧令牌和缺令牌请求都按明确策略拒绝或显式冲突确认；最新版本、首次保存、重复请求仍正常。

证据：独立复现结果 · 复现脚本 conflict · 并发保护实现

IA-06 · 入库接口的错误JSON字段类型返回500 P2
已复现的输入校验缺陷

当前证据：已登录且携带有效CSRF，POST /in_order/add，把business_type传为["产品入库"]，其余字段使用有效合成物料和仓库，返回500与“服务器内部错误”。空明细、负数量、无穷数量、未来日期和不存在仓库均被4xx拒绝。

原因 / 实现边界：routes/in_order.py:1084附近对JSON取出的business_type直接调用.strip()，缺少字符串类型校验；同类字符串字段应一并检查。

实际影响：正常页面通常不会生成数组类型，但畸形客户端请求会触发服务器错误，难以指导用户或集成方纠正。没有证据表明本次请求造成部分入库或数据库损坏。

建议：在进入业务逻辑前统一做输入类型校验，返回具体中文字段错误；覆盖同型字段和相邻出入库消费点，保留全部既有业务断言。

验收标准：数组、对象、空值、超长值等错误输入返回稳定4xx且不写单据/库存；合法JSON与现有表单提交行为不变。

证据：本轮20项独立场景 · 入库路由

IA-07 · 生产恢复模式仍主动暂停设备队列和微信发送能力 P2

实际影响：设备队列创建/设备控制及相关微信操作无法按常规运行。浏览器直接打印、模板预览、Excel导出属于不同链路，不能据此断言全部打印失效。

IA-08 · 工作目录、线上基线、覆盖文件与远端main并不相同 P2

证据：源码/覆盖校验 · 部署与main差异列表 · 当前CI与发布制品记录

IA-09 · 默认CSP仍允许内联脚本，前端注入的纵深防护较弱 P2
安全加固 / 技术债

当前证据：公网/login的实际CSP包含script-src self unsafe-inline；冻结模板143个，其中105个含内联脚本、82个含内联事件属性，共588个事件属性。

原因 / 实现边界：历史模板直接绑定onclick等事件，限制了全站启用更严格CSP的能力。个别页面有试点，不代表默认策略已经收紧。

实际影响：一旦某处出现HTML注入，CSP对内联脚本的阻断能力有限。本轮没有验证出可利用的XSS链，不能把588个属性计成588个漏洞。

建议：按页面实际使用频率逐批迁移事件绑定，先用报告模式收集违规，再逐页收紧；不应为一刀切CSP而让正常按钮失效。

验收标准：选定页面在真实Chrome全交互无正常CSP违规，恶意内联脚本测试被阻断；该页响应头不含unsafe-inline，随后再扩大覆盖。

证据：实际响应头 · 本轮模板静态清点

验收标准：用真实浏览器的可访问树能直接按“物料编码”“仓库”“第1行数量”定位；键盘录单顺序正确，无重复id。

IA-11 · 核心大文件和模板脚本仍使改动影响面偏大 P2

IA-12 · 生产主机只有约4GB内存，同机开发审计会明显占用余量 观察
