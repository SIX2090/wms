Excel模板下载

下载示例Excel模板，然后根据需要进行修改：

下载Excel模板文件 (.xlsx) 下载模板使用指南
Excel模板使用说明：
  1. 下载Excel模板文件
  2. 使用Excel打开模板文件
  3. 在模板中使用 {变量名} 格式插入字段
  4. 保存模板后上传到系统
  5. 在入库单页面选择该模板进行打印
使用示例
HTML模板示例：
<table>
    <tr>
        <td>单号：{{ '{{ order.order_no }}' }}</td>
        <td>日期：{{ '{{ order.date }}' }}</td>
    </tr>
    {% raw %}{% for item in order.items %}{% endraw %}
    <tr>
        <td>{{ '{{ item.material.name }}' }}</td>
        <td>{{ '{{ item.quantity }}' }}</td>
        <td>{{ '{{ item.price }}' }}</td>
        <td>{{ '{{ item.amount }}' }}</td>
    </tr>
    {% raw %}{% endfor %}{% endraw %}
    <tr>
        <td colspan="3">总计：</td>
        <td>{{ '{{ order.items|sum(attribute=\'amount\') }}' }}</td>
    </tr>
</table>
Excel模板示例：
A1: 入库单
B1: {order.order_no}
C1: 日期：{order.date}

A3: 供应商：{order.supplier.name}
B3: 联系人：{order.supplier.contact}

A5: 物料编码    物料名称    数量    单价    金额
A6: {item.material.code}  {item.material.name}  {item.quantity}  {item.price}  {item.amount}
