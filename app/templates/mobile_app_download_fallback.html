管理员部署 APP 下载的方式（任选其一）：
  1. 从 GitHub Release 免登录下载最新安装包（CI 每次自动构建更新）： github.com/SIX2090/wms/releases/download/android-apk/wms-mobile-scan.apk， 重命名为 app-release.apk 放到 WMS 仓库根目录（与 app/ 同级），本页自动恢复为直接下载；
  2. 设置环境变量 WMS_ANDROID_APK_URL 指向安装包地址（内网文件服务器，或上面的 Release 直链），本页自动跳转；
  3. 从 GitHub Actions 的 Android APK Build 工作流下载 app-debug 构建产物（需登录，90 天过期），按方式 1 放置。
