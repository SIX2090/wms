下载Excel模板文件 (.xlsx) 下载模板使用指南
Excel模板使用说明：
  1. 下载Excel模板文件
  2. 使用Excel打开模板文件
  3. 在模板中使用 {变量名} 格式插入字段
  4. 保存模板后上传到系统
  5. 在领料单页面选择该模板进行打印
使用示例
HTML模板示例：
<table>
    <tr>
        <td>单号：{{ '{{ order.order_no }}' }}</td>
        <td>日期：{{ '{{ order.date }}' }}</td>
    </tr>
    <tr>
        <td>客户：{{ '{{ order.customer|default(\'未指定\') }}' }}</td>
        <td>用途：{{ '{{ order.purpose|default(\'未填写\') }}' }}</td>
    </tr>
    {% raw %}{% for item in order.items %}{% endraw %}
    <tr>
        <td>{{ '{{ item.material.name }}' }}</td>
        <td>{{ '{{ item.quantity }}' }}</td>
        <td>{{ '{{ item.price }}' }}</td>
        <td>{{ '{{ item.amount }}' }}</td>
    </tr>
    {% raw %}{% endfor %}{% endraw %}
    <tr>
        <td colspan="3">总计：</td>
        <td>{{ '{{ order.items|sum(attribute=\'amount\') }}' }}</td>
    </tr>
</table>
