# 档案 Excel 导入与导出

2026-10-29：供应商、单位、物料分类、客户、仓库的普通导入和批量导入共用相同校验。

| 档案 | 必要列名 | 可选列名 |
|---|---|---|
| 供应商 | 供应商编号、供应商名称 | 联系人、电话、地址 |
| 单位 | 单位编号、单位名称 | 无 |
| 物料分类 | 分类编码、分类名称 | 上级分类编码 |
| 客户 | 客户编号、客户名称 | 联系人、电话、地址 |
| 仓库 | 仓库编码、仓库名称 | 仓库类型、仓库位置、状态、备注 |

按列名读取，可调整列顺序；首尾空白会去除。缺少必要列或列名重复时，在写入前拒绝整份文件。可以下载各页模板填写，也可使用相应档案的导出文件。额外的未知列不参与写入。

编码、名称为空的行跳过；重复编码或名称保持原档案，不覆盖。文件内同编码或名称以首次出现为准。

分类的上级编码可以引用已有分类或同份文件中的分类，不要求父级排在前面。多级依赖逐层解析；缺失上级、自引用、循环引用及依赖这些无效节点的行跳过，不创建孤立子级。导入提示分别列出导入和跳过数量。

仓库状态支持“启用”“停用”、`active`、`inactive`（英文大小写不敏感），空值默认启用，保存为 `active/inactive`。无效状态使整份文件回滚；导入不会改变默认仓库。历史中文状态保留原值，列表和状态筛选兼容读取，并显示“历史状态，请编辑确认”；请人工编辑选择启用或停用并保存后再用于业务选择或设为默认。未识别状态明确提示异常，不冒充停用。

供应商、客户、单位、仓库、部门、员工、分类的导出保留当前筛选和排序，导出筛选后的全部记录。分类排序在同级间进行，页面和导出均保留父级在前及完整树的层级；筛选后只导出命中记录，导入仍能独立处理历史文件中的父子行序。
