# 备份管理（2026-10-17）

系统管理 → 数据备份同时显示三类固定来源：

| 来源 | 位置 | 自动清理 |
| --- | --- | --- |
| 手动 / 历史备份 | 应用的 `backups` 目录；源码部署为 `C:\wms\app\backups` | 不自动清理 |
| 每日自动备份 | `WMS_BACKUP_DIR`，默认 `C:\wms_backups` | 默认最近30天，仅 `auto_daily_*.db` |
| 更新 / 维护目录 | 源码仓库根目录的 `backups`；扁平离线包使用应用的备份目录，不开放父盘目录 | 不由每日调度器清理 |

每日计划默认02:00；`AUTO_BACKUP_ENABLED`、`AUTO_BACKUP_TIME` 和 `BACKUP_RETENTION_DAYS` 沿用既有配置。保留天数的有效值与调度器相同：默认30，最少1；手动与更新前备份不因此删除。到期清理在每日备份成功后执行，浏览列表不会触发清理。页面展示配置，实际执行情况以文件记录和服务日志为准。

可按来源与文件名查询，点击列头排序会保留筛选；“清除”回到全部来源。目录相同时同一物理文件只显示一次，每日自动文件优先归入自动来源。创建手动备份后清除旧来源/关键词筛选并按时间倒序显示，便于立即找到新备份。

“下载”和“删除”均使用固定来源键与文件名，不接受任意文件夹路径；重名文件不会串来源，文件名按原样匹配。只允许管理员操作，删除须人工确认。当前业务库、链接和目录不能作为备份文件操作；某个来源读不到时显示提示，其他来源仍可用。

“校验”是显式、只读的SQLite物理完整性检查；列表不会逐个扫描整库。通过/未通过/未完成是本次检查结果，刷新后重新显示待复核。有事务旁文件或校验未完成时，使用离线维护副本进一步检查；不删除原文件，不自动恢复数据库。完整性通过不能替代恢复前的WMS结构校验与停机人工确认。

线上恢复仍禁用；恢复必须走现有停机维护流程。本次不移动生产备份，也不在生产执行删除/恢复。生产需重启 WMS 服务生效。
