# CI 分级验证操作说明

2026-11-13 按用户要求修订：多个任务同时推进，各自的问题各自闭环；不因一个任务等待 CI 让其他任务等待。main 分支策略、完整验证及生产边界保持。

## 多任务并行与共享 main

各任务分别记录目标、负责人、文件范围、本地验证、提交范围及完整目标 SHA，可以同时开发、提交、推送和等待自己的 CI。任务 A 的 CI 排队、运行、失败或查询异常，不阻止独立任务 B 继续工作。每个任务仍须通过自身目标的全部必需验证，不能把共享失败、取消、缺失或查询异常当成功。

不同文件可并行修改；同文件、配置或依赖有交集时先协调归属。修改共享暂存区、历史和远端的 Git 操作短暂串行，执行前后检查 HEAD、暂存内容和文件归属，不得纳入、覆盖或撤销他人改动。禁止 force push、破坏性同步或自动 stash。各任务的 CI 使用自己的提交快照，后续推送不自动取消较早目标的验收。

pre-push 保留 main 分支和 Windows 发行版本检查，不再查询远端 CI 阻断其他任务推送，也不需要 `WMS_SKIP_CI_GATE`。已知会引入新失败的代码不得推送；修复既有失败的纠正推送可以执行。实际失败由所属任务负责修复、复验或按 R8 回退自己的批次；B 的目标包含 A 的提交时，仍须验收该完整目标，不能把 A 的失败从 B 的结果中隐藏。

## 什么情况走轻量检查

仅限 main push，且本次全部文件都属于以下 Markdown 白名单：

- 根目录 `README.md`。
- `docs/ledger/` 下的 `.md` 文件。
- `docs/audit/` 下的 `.md` 文件。

还必须验证完整的 before/after 提交、祖先关系和文件差异，并确认 before SHA 的 WMS CI 与 WMS AI Verification 最近运行都为 `completed/success`。查询失败、基线未完成或失败时，不复用旧绿，改跑全量；这不阻塞推送。连续文档提交也必须逐次验证紧邻基线，不能越过一个未验证的代码提交。

轻量分支仍运行文档、月度台账及库存文档定位契约、严格 AI 台账一致性、规则及 gitleaks 凭据泄漏检查，并由聚合任务确认全部必需检查成功。工作流不会因为路径过滤而整体消失。

## 什么情况仍全量

任何业务代码、静态资源、模板、测试、依赖、脚本、工作流、`AGENTS.md`、`DEVELOPMENT_RULES.md` 或白名单外文件变化，都跑原全量 CI。定时、手动触发、PR 和未知事件也全量。无法确认变更范围时默认全量。

本地先跑受影响模块的修改前基线，再做回归锁、字节备份回退验证和模块全量/相邻回归；代码提交的全站测试交 CI 执行，避免本地和 CI 对同一批重复跑全站。不得以效率为由删除或放宽原业务断言。

## 各任务固定目标 SHA 验收

```powershell
# 查看实时远端main状态（不作为其他任务开工或推送的门禁）
python scripts/check_ci_green.py
# 固定本任务实际推送的完整40位目标SHA
python scripts/check_ci_green.py --target-sha <完整40位提交SHA> --json
```

WMS CI / AI 查询同一目标 SHA 在 main 的最新运行，不能使用其他 SHA 的绿替代，也不能因后续任务推进 main 而改验收目标。目标已实际推送且可从远端 main 到达、所需 CI 通过后即可完成；不要求后续 main 永远停在该目标。

Android 优先查询同一目标的最新构建；目标有失败、取消或运行中记录时不回退到旧绿。只有路径过滤导致目标没有构建时，才查询目标历史中最近修改 Android 输入的祖先提交的最新构建，并须证明成功、完整 Git 对象、祖先关系及 `app/android-native-wms/`、`.github/workflows/android-build.yml` 两个输入路径无变化。缺少历史或该来源无成功构建时保持未验收，不取其他任务的新构建替代。每天定时全量保留，性能工作流继续作为告警观测。

HTTP403、认证或网络错误表示该目标未核实，不代表 CI 已失败，也不影响其他任务。可通过连接器/Actions页面记录同一目标各工作流最新运行链接、完整 SHA、状态及 Android 复用证明，全部核实后才报告交付或发布。

## 生产发布

开发和 CI 并行不等于自动部署。生产部署/重启仍须明确授权，且实际加载的文件必须与已验收目标一致。生产与开发共用 `C:\wms` 时，不能将夹有其他任务未验收改动的工作目录冒充某个已绿 SHA 发布；应使用干净已验证的部署快照，或等待相关部署文件满足条件。生产数据库、账号和高风险业务操作边界不变。
