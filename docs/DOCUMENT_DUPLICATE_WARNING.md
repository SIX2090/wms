# 入库、出库的疑似重复提醒

2026-11-02 · R2-ISSUE-006 · BUG-2026-11-02-011 / 012

按用户本次确认的口径，同一天、同供应商的入库单，或同一天、同客户/部门的出库单，只有关键字段及全部明细一致才提醒。原来仅比较物料集合的规则由本规则替代；数量、价格偏离历史均值的检测仍不启用。

比较范围：

- 表头：日期、业务类型、供应商/客户/部门、仓库、库位、来源采购/销售/入库单、合同编号及关联档案、工程、用途、领料人等实际存在的字段。
- 明细：物料、数量、单价、金额、来源行、合同/工程，以及入库的批次、有效期和客供标记。库存单位由物料确定，入/出库明细模型没有可单独选择的单位字段。
- 全部行按内容和出现次数比较，行顺序不影响结果。物料相同而数量不同、一张单比另一张多行、同行物料拆成不同数量，均不视为完整一致。
- 数值用十进制数值比较，`0.1`与`0.10`等价；不对历史记录进行舍入或改写。空或非法明细、非有限数值不判作完整一致。文本空值与空字符串统一，去掉首尾空格。
- 单号、数据库ID、创建时间、操作人、单据状态和自由备注不作为重复内容字段。现有检测范围保持为今天的同往来方单据，包含草稿与已完成单；提醒不代表系统已认定重复。

例如同物料入库`0.10`与`0.20`不提醒；同日、同供应商、同仓库及其他关键字段均相同的两张`0.10`单据仍提示“疑似重复录入”。

正常完成仍需人工确认。出现疑似重复提醒后，“取消”保留草稿；“确认提交”即为继续完成的人工确认，不再重复弹出完成确认。请求期间保留防连点保护，异常弹窗未打开时其确认函数不发送完成请求。后端库存校验、写锁、权限及强制继续接口保持原有边界。
