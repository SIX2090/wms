# 入库列表导出与打印

2026-10-22 校订。

- 在入库列表勾选单据，再点击「批量导出」并确认，浏览器下载所选单据及明细的 `.xlsx` 文件。页面保留当前筛选和勾选；当前前端每次最多选择 100 张。
- 「打印已选（单张）」限选一张，确认后在当前页面打开该单据的打印页。多选时提示重新选择，不发送打印请求。多张单据合并打印尚未实现，不能把后端原先返回首张打印地址当成全部打印成功。
- 未选单据、取消确认、请求或业务失败时不下载、不导航、不刷新，页面显示失败原因；登录失效走统一重新登录提示。需要返回列表时使用浏览器返回或页面导航。
- 角色权限沿用已有后端要求，未增加提交、审批、完成、库存操作或打印机配置权限。

下载请求经 `WMS.api.postResponse(url, data, options)` 执行，与 JSON 请求共用 CSRF、同源凭据、HTTP 错误及 401/419 处理。成功时返回未读取正文的 `Response`，下载调用方须核对文件类型；JSON 业务错误或登录 HTML 不作为 Excel 保存。普通业务请求继续使用 `postRaw` 保留完整 JSON，或 `post` 自动解包。

模板修改生产需重启 WMS 服务生效；本项的提交、回归及生产验收以 BUG 台账对应记录为准。
