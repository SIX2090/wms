# 物料档案人工合并（2026-10-17）

在“基础资料 → 物料档案”中操作：

1. 点击某行“合并”，该行就是**被合并、最终删除的档案**。也可以勾选一个或两个物料，点击工具栏“合并物料”。
2. 按编码、名称、规格或品牌搜索，在候选列表点“保留此物料”。包含停用档案，支持翻页；系统不自动判定哪两个应当合并。
3. 核对“被合并 → 保留”的方向。可以点“交换保留方向”，交换后需要重新确认。
4. 查看两份档案的差异、库存合计和受影响记录。名称、规格、品牌不同只作提示，由操作员判断是否同一种物料，不必先修改成相同文字。
5. 勾选人工确认，再点击“确认合并”。取消或只预览不会合并。

合并会把历史单据、流水、期初及相关记录转到保留物料，库存累加，被合并档案删除。旧编码保留为别名；保留方的名称、规格、品牌和启停状态保持原值。此操作不可直接撤销，操作前应有可用备份。

库存单位不同不能直接累加数量，需要先核对换算关系及历史数量，另行处理，不能仅把单位文字改成一样来绕过。发生库存校验退化时，本次合并回滚，不应出现“报错但已经合并”。

本次代码包含模板改动，**生产需重启 WMS 服务生效**。自动测试及隔离页面验证不代表已在生产执行合并，也不代表已完成生产版本切换。
