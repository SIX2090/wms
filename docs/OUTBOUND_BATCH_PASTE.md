# 出库草稿批量粘贴

2026-10-22：修复详情页粘贴按钮原先调用缺失接口而返回404的问题。

## 使用入口与范围

普通领料单、其他出库单的草稿详情页，点击“粘贴输入”。管理员、仓管可操作；此操作仅新增草稿明细，不完成单据，不扣减库存。历史空类型和“生产出库”沿用领料口径。

销售出库、采购退货及任何带销售/采购来源的单据，请通过整单编辑维护来源明细，不能通过此入口追加无来源行。销售出库、采购退货及无操作权限角色的粘贴按钮禁用并给出说明；后端独立执行校验。已完成单据不能追加。

## 粘贴格式

每行：`物料编码,数量,单价`，也支持从Excel复制的制表符分隔内容。单价可省略或留空，此时采用物料默认单价；显式填写0则保留0。例如：

```text
M001,2,3.50
M002,5
```

数量必须为有限正数，单价为有限非负数，按系统现有两位小数规则处理；舍入后数量为0或金额超出系统精度时拒绝。最多500个非空行、总计100000个字符，只接收2或3列；物料必须已存在。重复编码分别保留为多行，不自动合并。

表头已有仓库必须有效；历史空仓仅在启用自动带出且有有效默认仓时，随成功保存一起写入默认仓。没有可用仓库或启用库位管理后表头缺库位时，请先编辑单据补齐。不会自动回填其他历史单据或库存账。

整批校验通过后同事务保存，并重新计算包含原有明细的合计。任意一行错误则整批不保存；按提示修正后可重试。

## 接口约定

`POST /out_order/<id>/batch_add_items`，需要登录、仓管操作权限及CSRF保护。请求为JSON：

```json
{"content":"M001,2,3.50\nM002,5"}
```

成功返回HTTP200：`{"status":"success","msg":"成功添加 2 行明细","added":2}`。输入、仓库、状态或来源约束不满足返回HTTP400及中文`msg`；单据不存在404，无登录/权限时分别401/403（AJAX），锁定状态冲突409，保存异常500并回滚。没有新增完成、审核或自动扣库存行为。
