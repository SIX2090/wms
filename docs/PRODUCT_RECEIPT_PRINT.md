# 产品入库单与打印格式

2026-11-05，FEAT-2026-11-05-107。

产品入库新增、编辑及详情页提供客户名称、合同编号和工程名称。客户从客户档案选择；合同编号、工程名称复用原表头字段，不另设重复字段。明细增加箱体编号，按文本保存，最长100个字符，保留前导零。旧单据箱体编号为空，不自动猜测或回填。

产品入库的默认网页打印及Excel下载使用用户提供的广东惠电产品入库格式：

| 打印位置 | 保存的数据 |
|---|---|
| 客户名称 | 表头客户档案名称 |
| NO | 表头合同编号，绝不使用入库单号替代 |
| 工程名称 | 表头工程名称 |
| 箱体编号 | 本行箱体编号 |
| 设备名称 | 本行物料档案名称 |
| 型号规格 | 本行物料档案规格 |
| 单位、数量、单价、金额、备注 | 本行对应数据 |

每页20条明细，不足补空行，超过20条逐页输出完整表头和签字区。多页合计及人民币大写金额按本页明细计算；各页合计之和等于全单明细合计。Excel每页单独工作表，使用A4纵向。复核人、送货人、收货人留空供人工签字；制单人和日期使用该单数据，不复制示例图片中的人名。

产品入库打印入口为 `/in_order/<id>/print`，默认Excel为 `/in_order/<id>/print_excel`。显式指定 `template_id` 的自定义Excel下载继续沿用原模板填充。采购、其他入库及销售退货的默认打印格式保持各自现有行为。专用模板文件是 `app/static/templates/product_receipt.xlsx`。

箱体编号支持新增、整单编辑、详情页直接编辑/新增、复制、草稿自动保存恢复；详情Excel导入可使用“箱体编号”列，文本批量追加的第七列为箱体编号；单据详情导出增加客户名称及箱体编号。打印及下载不完成单据，不改变库存。

## 上线要求

模型新增可空列 `in_order_item.box_no VARCHAR(100)`。在现有旧库启动新代码前，按[显式结构升级说明](SCHEMA_UPGRADE.md)备份、停服并应用本批[审阅后的补列语句](audit/2026-11-05-product-receipt-schema.sql)，然后沿原托管入口重启；**生产需重启 WMS 服务生效**。`WMS_NO_DB_TOUCH=1`不会自动加列，不能只重启而漏掉升级。生产结构升级与服务操作须取得本次明确授权；通用结构预览列出的其他存量事项另行处理。

验证均在合成/隔离数据库执行，不以真实单据完成、反提交或库存修改作验收。
