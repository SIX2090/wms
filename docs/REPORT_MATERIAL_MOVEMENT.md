# 物料收发存汇总（2026-10-26）

进入“出入库汇总报表”默认显示按物料收发存；可切换“按日期汇总”。首次打开按物料视图默认本月，选择“不限日期”后刷新仍保持不限日期。

每个仓库、每种物料一行，显示编码、名称、规格、单位、期初数量、本期入库、本期出库和期末结存。顶部数量按单位分别合计，不把件、米等直接相加。物料编码可联查同仓、同期间、同一物料ID的库存台账；重新搜索其他物料后解除原物料ID约束。

## 数量口径

- 期初：开始日期之前的已生效库存变动累计。
- 本期：开始、结束日期均包含当天；未设开始日期时从建账开始统计，期初为0；未设结束日期时不限制上界。
- 入库、出库：本期库存增加和减少的绝对数量，包含期初建账、调拨、盘点调整、售后及委外等实际库存变动。期内录入的期初建账按其业务日期计为本期增加，不能再重复计为查询期初。
- 期末＝期初＋本期入库－本期出库。只在查询期末之后发生过变动的物料不出现；仅有期初、期间无变动的物料仍保留。
- 来源为库存流水事实，业务日期及历史仓库归属复用库存台账的同源规则；有来源单据用单据日期，否则用流水日期。无法确认多仓归属的历史记录不猜到默认仓库；草稿没有已生效库存变动，不参与余额。
- 此视图只提供数量收发存，不用当前物料单价倒算历史存货成本，不替代财务成本核算。

## 查询、输出与兼容

网页查询、分页、汇总、完整Excel导出、网页全量打印、Excel模板打印使用同一行集。库存流水按ID分批取全，不复用台账明细的50000行显示上限。只读查询不修改库存或单据。

`GET /report/api/material_movement` 使用原报表分页响应协议。参数：`warehouse_id`（必填，可按原规则带默认仓）、`start_date`、`end_date`、`material_code`（关键词）、`hide_zero=1`（隐藏期末为0）、`page`、`page_size`、`sort_field`、`sort_order`；`export=excel` 导出筛选全集。模板输出为 `/report/material_movement/print_excel`，单独使用 `report_material_movement` 模板目标，不覆盖原日报用户模板。

原 `/report/api/summary` 继续提供日期业务汇总，`/report/view/summary?summary_view=daily` 打开原视图。其原行数指标明确标为“入库明细行数／领料明细行数”，不再标成单据数。
