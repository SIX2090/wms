# 仓库月报

2026-11-17 修订，BUG-2026-11-17-008；沿用 BUG-2026-10-26-003 的业务日期和仓库归属口径。

入口：库存管理 → 仓库月报，`/report/view/warehouse_monthly`。选择仓库、开始月份及结束月份，可快捷选择本月、上月、本年。清空条件保留当前仓库、恢复本月。

每行是一个仓库内一个物料在所选期间的收发存，不显示月份列，也不按月重复列物料：期初结存＋期间入库－期间出库＝期末结存。“本年”从当年1月至当前月，例如2026年11月查询本年，统计2026-01至2026-11，8月发生额合并进期间收发。按来源单据的业务日期判断期间，无法解析来源日期时使用流水日期；补录不因录入时间跨月而错月。期内建账、调拨、调整等已生效库存事实均参与，草稿不计入。所选月份覆盖完整自然月，旧日期区间链接按其所在月份解释。

普通浏览只显示本仓有期初、期间发生或结存的物料；期间全零且无发生不铺行，只有历史结存也须显示。精确输入完整物料编码时允许显示该物料的零行，供核对仓库无记录。勾选“期末结存等于0不显示”按所选期间期末余额过滤物料。供应商是物料主档供应商筛选，不改变已选物料的库存收发口径。

总览按单位分组，与明细全集逐项一致：期初取开始月份前余额，入库/出库取期间合计，期末取结束月份末余额；不同单位不混加，各月结存不累加。行数等于物料数，翻页不改变汇总。点击物料编码携带精确物料ID、仓库、所选期间首日和末日联查台账。单据数在整段期间按来源单据去重。查询、排序、导出Excel、网页打印及模板打印使用同一行集；保留原 `report_warehouse_monthly` 模板目标和数量、金额字段，移除 `month` 字段。自定义模板如曾引用 `month`，应删除该占位或列。

价格维度关闭时不展示金额字段。开启后的出入库金额使用来源单据实际单价（含真实零价）；委外收货单的单价是单位加工费，加工费金额保留在收货单。月报按收货数量乘物料当前参考价估值，分别在入库、出库金额中列出委外收货及冲回的参考估值，两列均为其中数。例如实收 3 件、单位加工费 2 元、物料参考价 99 元，收货单加工费为 6 元，月报入库参考估值为 297 元。其他无来源价流水及期末估值沿用当前物料参考价。这是兼容性的参考估值，不是历史财务成本，未增加成本核算或结账功能。

API仍为 `GET /report/api/warehouse_monthly`，新增可选 `start_month=2026-09&end_month=2026-10`，优先于兼容的 `start_date/end_date`。缺省本月，倒置或非法月份返回400。仓库必填、默认仓库及无效仓库处理沿用统一约定。数量汇总在 `summary.unit_totals` 中，字段为 `beginning_quantity/in_quantity/out_quantity/ending_quantity`；混合单位时旧 `summary.quantity` 返回null，避免提供无意义合计。`summary.amount` 为末月参考估值。数量用Decimal累计，不受台账50000行显示上限截断。

设计参照：[金蝶云星空物料收发汇总表](https://open.kingdee.com/K3Cloud/help/STK_STOCKSUMMARYRPT.html)的期初、收入、发出、结存和无期初无发生过滤结构；月初由上期结存结转的说明参照[金蝶收发存明细报表](https://help.open.kingdee.com/dokuwiki/doku.php?id=%E9%A4%90%E9%A5%AE%E5%AD%98%E8%B4%A7%E6%94%B6%E5%8F%91%E5%AD%98%E6%98%8E%E7%BB%86%E6%8A%A5%E8%A1%A8)。本WMS按现有数量登记范围实现，参考说明不代表复制其财务、组织或审批功能。
