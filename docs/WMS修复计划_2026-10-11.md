## 0. 总则与执行纪律

1. **CI 门禁前置（AGENTS.md §三）**：`WMS CI` 当前红灯（#1450 failure）。按规则**门禁恢复前禁止提交任何 atomic action**——因此阶段 0 优先于一切；本计划文档本身在 CI 转绿后随首个 docs commit 一并提交。
2. **提交粒度**：每个任务拆为 1–N 个 atomic action（可独立 revert、自过 lint/测试、规范 commit message），各自 commit + push 到 `main`（禁止新分支）。
3. **验证后汇报**：每个 atomic action 推送后读取实际 push 输出确认新 SHA；CI 转绿前后的状态用 `python scripts/check_ci_green.py` 确认。
4. **数据库红线**：全程不直接写生产库（`WMS_NO_DB_TOUCH.flag` 保护）；涉及 schema 的任务全部走停机窗口 + 先验证备份可恢复。
5. **业务铁律（AGENTS.md §一）**：所有修复仅改代码与配置，不代用户做单据提交/审核/删除；密码相关改动（F2.1）仅打开强制改密逻辑，不代设密码。
