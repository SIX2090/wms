# 产品入库详情与销售出库转换修正

2026-11-06，关联 BUG-2026-11-06-002、BUG-2026-11-06-003，以及既有 FEAT-2026-11-05-107 / FEAT-2026-11-06-001。用户明确产品入库表示生产成品入库，并要求修正详情栏目、箱体编号、明细排序和转为销售出库入口；本批先完成这些项目，之后另查全 WMS 详情与单据的一致性。

## 详情与栏目

原顶部栏目按钮没有明确表格目标，公共面板按容器内首张表定位。前置的采购来源或下推记录表被当作明细，出现关系、供应商、来源采购单等错误栏目。产品和采购详情又共用列顺序、列宽；新增箱体列被旧采购顺序追加到末尾。原产品详情确有箱体数据的服务端渲染，不能将截图中的不可见直接解释为数据库没有保存。

修正后，产品顶部入口明确绑定 itemTable；同根因排查同时为入库新增的 materialTable、报表的 reportTable 增加明确绑定。产品详情使用独立的栏目存储范围、顺序和列宽键，旧采购配置保留。默认箱体编号为首个业务列，表头、已有行、草稿新增行和合计行按相同字段键对齐；空态按业务类型计算实际列数。

生产成品详情不再显示来源采购单、供应商的空采购联查，也不再显示采购数量、已下推、已入库、来源状态等五项采购执行列。真实的下游单据记录仍可查看。采购、其他入库和销售退货的既有采购追溯列保留；没有修改这些业务的库存规则。

产品明细列头支持点击升序/降序和 Enter / 空格键操作。箱体编号采用自然顺序，数量、单价、金额等按数值排序；空值后置，同值保留当前相对顺序。排序移动整行原节点，按字段键取值，适应调列、隐藏及正在编辑的输入框；只改变当前页面的显示顺序，不写单据、库存或数据库行序。

## 成品转为直接销售出库

旧 convert_to_out_order 接口仅允许产品入库，但仍生成 OUT 领料单，未完整复制客户、合同、工程和库位；另一个旧 copy_to_out 入口也会把产品复制成领料单。

现有转换接口保持 URL 和权限、单据版本保护，改为生成 SO 编号、业务类型为“销售出库”的 pending 草稿。继承客户名称、来源仓库/库位、合同工程、逐行数量、价格、备注及行级合同工程，重新计算金额；无来源销售订单也能使用既有直接销售出库流程。客户缺失、无明细、错误仓库或异常数量价格均拒绝；历史空仓库沿用既有默认仓处理，无默认则拒绝。产品的旧 copy_to_out 入口转入同一逻辑，其他业务保留原复制行为。

使用现有来源单写锁和 DocumentPushLine 记录产品来源行到销售目标行，保留每条箱体的来源身份，不合并重复物料。两个操作员或重复点击同一来源时打开已有有效销售草稿；不重复创建。下游存在时保护来源反提交，删除销售草稿时释放关联，再转换使用新关联请求。详情关联记录、目标链接、单张/批量删除及普通重建明细保护一并支持 sales_out。没有把产品来源写入专用于采购退货的 source_in_order 外键，避免销售完成被误判为采购退货。

转换仅生成草稿，不直接扣减库存；人工完成销售出库沿用既有仓库库存和流水链路。箱体身份通过来源行关联保留；本批没有为 OutOrderItem 新增独立箱体字段或进行数据库迁移，销售详情的箱体展示属于后续字段一致性检查范围。
