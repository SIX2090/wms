# 统一单据打印验收

2026-11-07，关联BUG-2026-11-07-003。

用户要求所有单据使用同一种打印方式。入口统一为“打印”，随后选择Excel模板、预览填好的单据，再点击打印。下载保留为辅助操作。预览和下载共用同一份版式保留后的文件；不调用提交、审批、完成、库存或模板设默认接口。

## 范围与计数

15种模型：采购申请、采购订单、销售订单、入库单、出库单、售后出库、调拨、盘点、调整、领料申请、委外加工、委外发料、委外收货、BOM、期初库存。入库和出库各细分4类，合计21类业务单据。这是单据范围计数，不是BUG数量。

保存后的详情、原有列表行打印、全局动作及入库“打印已选（单张）”进入同一流程。新期初单须先保存，避免把编辑器和未保存数据当作正式打印内容。既有打印队列、物料标签、物料档案及独立报表属于不同输出对象，其业务取数和队列执行保持原有边界；报表按钮文案同步明确为网页打印、下载Excel打印文件、模板设置。

## 数据与版式

复用原有单据取数与Excel填充；新流程通过请求内标记启用已存在的报表版式保留算法，原Excel下载接口默认行为兼容。BOM新增注册与只读出口，期初从所选单据lines读取，不混入其他单据或历史未归单余额。期初合计使用只读包装，不赋值ORM字段。

新增预览支持合并、常见字体与数值格式、图片、打印区域、隐藏行列、纸张方向和边距、纵向分页、首行起的重复标题及常用页码页脚。产品入库每页20行、采购申请每页15行专用模板沿用原实现；柜号保留文字。

不可靠内容（公式、图表、多打印区域、条件格式、部分特殊文字或页眉页脚等）返回明确错误，页面没有打印按钮，可下载原Excel或调整模板。浏览器字体度量与Excel可能不同，打印前仍须核对预览和打印窗口设置。未执行物理出纸。
