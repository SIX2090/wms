# Android 凭据来源与会话切换修复（2026-11-13）

对应 BUG-2026-11-08-014，兼作 11-08-012 队列归属修复的传输层前置。基线 `b7eb809d7f51c59569de30c332ba01649854202b`；WMS CI 43380025639 与 AI 43380025585 为精确 success，Android 43331615930/3652607a 为祖先且源码/工作流输入未变。没有生产数据库、凭据、HTTP、打印、微信或部署操作。

## 根因与改动

- 共享客户端以前无条件注入当前全局令牌；Coil 外域图片和旧 Retrofit 实例都可混用新令牌。现在 API 实例绑定不可变会话快照，来源比较完整 scheme/host/port，陈旧 API 请求发送前明确失败；图片外域请求去除 Authorization。登录请求不带旧 Bearer。
- 应用拦截器和每跳网络拦截器复核来源。API 跨来源重定向停止，不转发业务体；图片重定向按每跳来源处理凭据。未配置服务器继续抛错，不回退真实域名。
- 401 处理核对来源与会话代次，旧响应不能清除新令牌。异步 AuthEventBus 同时携带代次；仓库对登录持久化与登出加互斥，过期事件不能延迟清掉新凭据。
- 登录保存、请求前冷恢复及 AuthViewModel 冷恢复一起排查。服务器与令牌原子发布；过期冷恢复不能覆盖新登录，同一凭据的两个恢复者保持幂等。
- 原 12 项 Python 取证模型中，五项原来断言风险仍存在；本次将已修复的传输部分改为源码契约，保留其余未修队列风险模型。冷恢复旧测试改为核对原子恢复且仍先于放行登录界面，不删除原认证及跳转保护。
