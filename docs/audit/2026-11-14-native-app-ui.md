## 已确认问题与实现

1. 出入库明细、每日报表、库存日报均将数量限制为 110dp、单行、省略号；库存台账的发生量和行后结存、盘点记录账面/实盘/差异也限制单行。五类行统一为资料区加完整数量区，保留 formatQty、tnum、符号、单位及原数据来源，支持换行；台账选料摘要、入库确认总量及语音解析数量摘要也取消关键数量省略。四个顶部汇总卡经真实测量确认存在同类宽度问题，改为可换行的两列、数值明确占宽；原计数、汇总来源和口径全部保留。显示层只在千分位逗号后增加不可见断行机会，使长数可在数群间换行并保留小数部分；不修改库存、精度、汇总、输入或接口。
2. 次级文字、语义色和模块徽章存在低对比度；主题常用文字令牌调为可读颜色，徽章按实际不透明背景确定文字色。渐变头部保证固定白字与起止背景对比；暗色阴影保持黑色。首页仓库按钮原白色 15% 叠加使白字约为 3.84:1（原始蓝背景约 5.02:1），换为共用深色半透明底；同类退出及返回图标一并接入。汇总文字按实际合成背景调整对比。公共按钮使用最小高度，容纳放大文字。
3. 手工数量错误仅短暂提示，和已有行编辑/期初体验不一致；增加字段附近持久说明和错误态，保留输入及 Done 回调。盘点已有 allowZeroQuantity=true 和 ViewModel 零盘规则，但两处添加回调误用正数解析，改为遵守已有零盘规则。拒绝非有限数量，不扩大其他页面的零值范围。手工输入使用 rememberSaveable，弹窗正文可滚动。
4. 首页卡片与 Tab 的一级导航栈不同；统一已保存的一级入口，包含识物查库存及既有语音预填消费点，保留来源预填和人工确认。
5. 既有队列 pendingCount/failedCount 是本机总数。新增只读 QueueDisplayState，按稳定服务器、用户 ID、会话代次筛选显示；扫码页面和全局状态共用同一投影。历史归属不明记录只给通用人工核对提示，不显示其他账号数量或错误详情。原始 DAO、回放、幂等、退避和重试规则不变。
6. 首页保留三列及十四个入口。此前用户有意移除逐卡副标题，本次不恢复信息堆叠；分组增加用途说明、主入口字体提高，名称继续完整换行。
