# 库存管理报表审计 · 2026-11-22

审计范围为桌面「库存管理 → 报表」的 13 个入口。按菜单逐项核过页面与后端，再测试共用的查询、分页、导出和打印路径。验证使用隔离 SQLite 合成数据。浏览器使用实际模板、脚本及隔离接口返回的数据。生产数据核账和现场打印未纳入本轮。

| 报表入口 | 核对结果 |
|---|---|
| 数据仪表盘 | 已完成的普通领料及已识别的历史领料计入本月、上月、近十天和近六个月。检查跨仓重名、零基数环比、库存单位切换。 |
| 全部入库明细报表 | 核对入库类型、状态、仓库、按单位合计、导出及打印。修复按客户查询时返回其他客户记录的问题。 |
| 其他入库明细报表 | 核对菜单预置类型、客户筛选及客供标记。页面和系统打印标题随筛选变化。 |
| 其他出库明细报表 | 按原单客户或领用单位查询、排序及输出。覆盖旧单混有部门和客户的情况。 |
| 库存报表 | 校验仓库归属、零库存、负库存、分页与导出。不同单位的结存分别汇总。 |
| 领料明细报表 | 验证默认领料范围、历史类型、按客户或部门筛选及按单位合计。显式业务类型筛选仍可单独查看。 |
| 出入库汇总报表 | 核对物料收发存的期初、期间发生和期末、跨仓隔离及跳转台账。逐日视图按日期和单位分行。 |
| 盘点报表 | 卡板逐行显示已盘数量，同物料冻结账面只列一次。盘齐后计算净差异，部分盘点显示待盘组数。检查分页、排序、汇总、导出与 AI 差异分析。 |
| 库存台账 | 复核精确选料、历史期初、同编码前缀、调拨/反冲归仓、四位小数、分页和打印。 |
| 仓库月报表 | 复核月份范围、上期结转、零数量筛选、仓库边界、按单位合计、导出全量及台账链接。 |
| 工单领料报表 | 核对仓库、物料筛选、空明细订单、分页和金额。数量按单位展示，金额按当前物料参考价估算。 |
| 委外加工报表 | 按订单仓库和日期跟踪。实际发料和收货只累计已完成子单，按单位展示，零收发订单保留。 |
| 库存预警 | 对照全局与单仓阈值、两档预警和开关。失效仓库按原规则回到全局，并说明原因和当前范围。 |
