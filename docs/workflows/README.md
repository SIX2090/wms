## 覆盖范围

30专题：总览、基础资料、期初、普通单据、采购申请、采购订单、入库、普通出库、销售、销售退货、采购退货、BOM/工单领料、调拨、PC盘点、扫码盘点、调整、委外、售后、库存三账、报表、手机扫码、导入导出/附件、标签/模板、打印队列、AI OCR、AI Agent、权限/审计、微信分享、备份恢复、GitHub更新与生产启动。

附录还包含16组对象状态/库存影响、14类通用报表、97个去重菜单链接和702条静态路由声明。当前扫描识别96个数据库模型类。静态声明数量不等于当前部署启用数量，也不等于去重后的运行时路由或数据库表数量。

## 关键口径

1. 草稿、业务完成、订单履约、AI识别与打印任务分别管理。
2. 采购来源预留量与实际完成入库量分开说明；采购入库可以手工录入，采购订单是可选来源。
3. 盘点完成生成调整草稿，调整完成才改库存；扫码记录completed不表示批次或调整完成。
4. 普通OutOrder领料与ProductionRequisition工单领料不是同一单据；BOM领料不等于完整生产ERP。
5. 关闭库位时总账=流水净额；开启库位时才要求总账=库位汇总=流水净额。
6. 手机批量草稿路径和快速直接完成路径、委外常规子单和快捷发料/收料分别标出。
7. 采购订单关闭/重开、销售取消、工单领料/调拨反提交按当前实际路由核对，不照搬旧注释。
8. AI能力受配置、角色、灰度与人工确认控制；本册不把规划能力画成默认已启用。

## 验证与维护

生成命令（需要reportlab与可用中文字体）：

```powershell
python C:/wms/docs/workflows/build_atlas.py
```

内容在`flow_content.py`，生成器不导入WMS业务程序、不读取生产数据库。图文共用同一数据源；会检查专题ID、节点位置、回退目标、文本容量和118处证据路径/符号。`manifest.json`记录页数和扫描数量。

本轮已生成全部66页PNG用于排版检查，并核对PDF无空页、中文可提取、30章节书签；浏览器检查预览连接、搜索、专题切换及图文显示。最终提交与CI结果以实际任务输出为准。

业务代码变化时须先重新核对状态和库存影响，再更新图源；不能只机械地刷新源码SHA。流程图不是生产业务操作授权，本轮未提交生产单据、调整库存、恢复数据库或修改账号。
