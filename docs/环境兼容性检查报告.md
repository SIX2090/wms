## 二、配置文件检查项

| 配置项 | 当前值 | 位置 | 需修改 | 修改建议 |
|---|---|---|---|---|
| 服务监听地址 | `0.0.0.0`（公网暴露） | `run_server.py:101` | 是 | 生产环境改为 `127.0.0.1`，由 Nginx 反向代理对外 |
| 服务监听端口 | `8080`（硬编码默认） | `run_server.py:102` | 是 | 通过环境变量 `PORT` 配置，避免与其他服务冲突 |
| 安装路径（C 盘） | `C:\WMS` | `install.bat:10` | 视情况 | 与 `deploy_cloud.bat` 的 `C:\wms` 大小写不一致，统一为 `C:\wms` |
| 安装路径（E 盘） | `E:\wms` | `install_e_wms.bat:10` | 视情况 | 仅 E 盘服务器使用，确保 E 盘存在 |
| 安装路径（云部署） | `C:\wms` | `deploy_cloud.bat:18` | 否 | 固定路径，与文档一致 |
| Nginx server_name | `gd2026.top www.gd2026.top`（硬编码） | `nginx_wms_server_block.conf:7` | 是 | 根据实际域名修改 |
| SSL 证书路径 | `server.pem` / `server.key`（相对路径） | `nginx_wms_server_block.conf:9-10` | 是 | 改为绝对路径，如 `C:\nginx\ssl\server.pem` |
| 数据库连接字符串 | `sqlite:///inventory.db`（默认 SQLite） | `config.py:13` | 是（如用 MySQL） | 通过环境变量 `DATABASE_URL` 配置，如 `mysql+pymysql://user:pass@host:3306/wms` |
| GitHub 凭据 | PAT 明文写入 `.git-credentials` | `deploy_cloud.bat:101` | **是（高危）** | 改用环境变量 `GITHUB_TOKEN` 或 Windows 凭据管理器，撤销已泄露 PAT |
| TLS 1.2 注册表 | 默认未启用 | WinHTTP | 是 | 执行注册表配置（见下方） |

### TLS 1.2 启用注册表配置（Server 2012 R2）

```reg
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Internet Settings\WinHttp]
"DefaultSecureProtocols"=dword:00000AA0

[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\SecurityProviders\SCHANNEL\Protocols\TLS 1.2\Client]
"Enabled"=dword:00000001
"DisabledByDefault"=dword:00000000

[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\SecurityProviders\SCHANNEL\Protocols\TLS 1.2\Server]
"Enabled"=dword:00000001
"DisabledByDefault"=dword:00000000
```

## 三、结论

- Server 2012 R2 默认环境缺失 6 项关键运行时依赖（WMF 5.1、.NET 4.8、VC++ 运行时、Python、Git、TLS 1.2）。
- 4 项 Python 包 CVE 已在本次修复中升级（Flask/Werkzeug/cryptography/urllib3）。
- 配置文件存在 9 项需根据目标服务器修改的项，其中 GitHub PAT 明文为最高风险。
