## 一、部署后健康检查 PowerShell 脚本

脚本文件：`scripts/health_check.ps1`（见同目录）

该脚本执行 10 项检查：服务状态、端口监听、HTTP 响应、登录页可达、数据库文件存在、日志生成、SECRET_KEY 持久化、auto_update 日志、Nginx 代理、防火墙规则。

```powershell
# 运行方式（管理员 PowerShell）：
cd C:\wms
.\scripts\health_check.ps1
# 或指定安装路径：
.\scripts\health_check.ps1 -InstallDir C:\wms -Port 8080
```

## 二、部署验证检查表

| # | 检查项 | 验证命令 | 预期结果 | 异常处理 |
|---|---|---|---|---|
| 1 | nssm 服务状态 | `nssm status WMS` | `SERVICE_RUNNING` | 查看事件查看器 → Windows 日志 → 应用程序；检查 `logs\service_stderr.log` |
| 2 | 服务进程存在 | `Get-Process -Name python -ErrorAction SilentlyContinue` | 返回 python.exe 进程 | 服务未启动：`nssm start WMS`；启动失败：检查 Python 路径和依赖 |
| 3 | 8080 端口监听 | `Get-NetTCPConnection -LocalPort 8080 -State Listen` | 返回 LISTENING 状态连接 | 端口被占：`netstat -ano \| findstr 8080` 找到 PID 后 `Stop-Process -Id <PID>` |
| 4 | HTTP 本机响应 | `Invoke-WebRequest -Uri http://127.0.0.1:8080/login -UseBasicParsing` | `StatusCode = 200` | 服务未启动或路由错误；检查 `logs\app.log` 和 `service_stderr.log` |
| 5 | 登录页内容 | `(Invoke-WebRequest http://127.0.0.1:8080/login -UseBasicParsing).Content -match 'login'` | `True` | 模板缺失或 Jinja2 渲染错误；检查 `app\templates\` 目录 |
| 6 | 数据库文件存在 | `Test-Path C:\wms\app\instance\inventory.db` | `True` | 数据库未初始化；检查 `WMS_NO_DB_TOUCH.flag` 是否存在，删除后重启服务 |
| 7 | 应用日志生成 | `Test-Path C:\wms\logs\app.log` | `True` 且文件大小 > 0 | 日志目录权限不足；检查 `logs` 目录 ACL |
| 8 | SECRET_KEY 持久化 | `Test-Path C:\wms\app\instance\secret_key` | `True` | 首次启动未生成；检查 `WMS_ALLOW_AUTO_SECRET_KEY` 环境变量 |
| 9 | Nginx 公网代理 | `Invoke-WebRequest -Uri https://gd2026.top/login -UseBasicParsing` | `StatusCode = 200` | Nginx 未运行：`net start nginx`；SSL 证书过期：续签证书 |
| 10 | 防火墙规则 | `Get-NetFirewallRule -DisplayName "WMS*"` | 返回 WMS 相关规则 | 规则缺失：`New-NetFirewallRule -DisplayName "WMS-HTTPS" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow` |
| 11 | auto_update 日志 | `Select-String -Path C:\wms\logs\service_stdout.log -Pattern "AUTO_UPDATE"` | 包含更新检查记录 | auto_update 未触发；检查 `WMS_SKIP_AUTO_UPDATE` 是否设为 1 |
| 12 | Python 依赖完整 | `& C:\wms\python\python.exe -c "import flask, sqlalchemy, waitress; print('OK')"` | 输出 `OK` | 依赖缺失：`pip install -r requirements.txt` 或从 wheelhouse 安装 |
| 13 | 磁盘空间 | `Get-PSDrive C \| Select-Object Used,Free` | 剩余空间 > 1GB | 清理 `logs`、`backups` 旧文件 |
| 14 | 数据库可读写 | `& python -c "import sqlite3; c=sqlite3.connect('C:/wms/app/instance/inventory.db'); print(c.execute('SELECT COUNT(*) FROM user').fetchone())"` | 返回用户数 ≥ 1 | 数据库锁定或损坏；从 `backups` 恢复 |
| 15 | CSRF 令牌生成 | `(Invoke-WebRequest http://127.0.0.1:8080/login -UseBasicParsing).Content -match 'csrf_token'` | `True` | Flask-WTF 未正确加载；检查 `WTF_CSRF_ENABLED` |
| 16 | 安全响应头 | `(Invoke-WebRequest http://127.0.0.1:8080/login -UseBasicParsing).Headers['X-Content-Type-Options']` | `nosniff` | ProductionConfig 未生效；检查 `FLASK_ENV=production` |
| 17 | Session Cookie Secure | 检查登录响应 Set-Cookie 头 | 包含 `Secure` 标志 | SESSION_COOKIE_SECURE 未生效；检查环境变量 `SESSION_COOKIE_SECURE` |
| 18 | 备份目录存在 | `Test-Path C:\wms\backups` | `True` | 手动创建 `mkdir C:\wms\backups` |
| 19 | 上传目录存在 | `Test-Path C:\wms\static\uploads` | `True` | 手动创建 `mkdir C:\wms\static\uploads` |
| 20 | WMS_NO_DB_TOUCH 标记 | `Test-Path C:\wms\app\WMS_NO_DB_TOUCH.flag` | 更新场景为 True，全新部署为 False | 全新部署不应存在；如误存在则删除后重启 |

## 三、回滚验证步骤

| # | 步骤 | 验证命令 | 预期结果 | 异常处理 |
|---|---|---|---|---|
| 1 | 停止 WMS 服务 | `nssm stop WMS` | 服务状态为 STOPPED | 服务卡死：`taskkill /F /IM python.exe`（注意影响范围） |
| 2 | 确认进程已退出 | `Get-Process -Name python -ErrorAction SilentlyContinue` | 无返回（无 python 进程） | 进程残留：`Stop-Process -Name python -Force` |
| 3 | 确认端口已释放 | `Get-NetTCPConnection -LocalPort 8080 -State Listen -ErrorAction SilentlyContinue` | 无返回 | 端口未释放：等待 30 秒或强制杀进程 |
| 4 | 删除 nssm 服务 | `nssm remove WMS confirm` | 输出 "Service removed" | 服务不存在：跳过此步 |
| 5 | 确认服务已删除 | `nssm status WMS` | 输出 "Service does not exist" | 注册表残留：`sc.exe delete WMS` |
| 6 | 停止 Nginx | `net stop nginx` 或 `nginx -s stop` | Nginx 进程退出 | 进程残留：`taskkill /F /IM nginx.exe` |
| 7 | 删除防火墙规则 | `Remove-NetFirewallRule -DisplayName "WMS-HTTPS"` | 规则删除成功 | 规则不存在：跳过此步 |
| 8 | 确认防火墙规则已删除 | `Get-NetFirewallRule -DisplayName "WMS*" -ErrorAction SilentlyContinue` | 无返回 | 规则残留：手动在高级安全防火墙中删除 |
| 9 | 恢复数据库备份 | `Copy-Item C:\wms\backups\before_*_inventory.db C:\wms\app\instance\inventory.db -Force` | 文件复制成功 | 备份不存在：从其他备份介质恢复 |
| 10 | 卸载 Python 依赖（可选） | `pip uninstall -r C:\wms\app\requirements.txt -y` | 全部卸载成功 | 部分包卸载失败：手动 `pip uninstall <package>` |
| 11 | 删除安装目录（可选） | `Remove-Item C:\wms -Recurse -Force` | 目录删除成功 | 文件被占用：先停止所有相关进程 |
| 12 | 删除桌面快捷方式 | `Remove-Item "$env:USERPROFILE\Desktop\WMS.lnk" -Force` | 文件删除成功 | 文件不存在：跳过此步 |
| 13 | 清理日志（可选） | `Remove-Item C:\wms\logs\* -Force` | 日志文件删除成功 | 目录不存在：跳过此步 |
| 14 | 清理 .git-credentials | `Remove-Item "$env:USERPROFILE\.git-credentials" -Force` | 文件删除成功 | 文件不存在：跳过此步 |
| 15 | 删除 WMS 服务账户（如创建） | `net user WMS_Service /delete` | 命令执行成功 | 账户不存在：跳过此步 |
| 16 | 清理环境变量 | `[Environment]::SetEnvironmentVariable("GITHUB_TOKEN",$null,"Machine")` | 变量已清除 | 变量不存在：跳过此步 |
| 17 | 验证回滚完成 | `Get-Service WMS -ErrorAction SilentlyContinue; Get-NetTCPConnection -LocalPort 8080 -ErrorAction SilentlyContinue` | 均无返回 | 如有残留：重复上述步骤 |

## 四、回滚决策树

```
部署失败
├─ 能否访问旧版本代码？
│   ├─ 是 → git checkout <上一稳定commit> → 重启服务 → 验证健康检查
│   └─ 否 → 执行完整回滚（步骤 1-17）
│       ├─ 数据库是否需要恢复？
│       │   ├─ 是 → 步骤 9 恢复备份
│       │   └─ 否 → 跳过步骤 9
│       └─ 是否需要完全卸载？
│           ├─ 是 → 步骤 10-16 完全清理
│           └─ 否 → 仅步骤 1-8 停服务删规则，保留文件
└─ 回滚后验证：步骤 17 确认无残留
```
