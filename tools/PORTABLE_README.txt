WMS Windows 离线便携版 2026.11.2

1. 将整个文件夹解压到一个新目录，不要覆盖旧安装。
2. 首次使用双击 setup_first_run.bat，选择 Y 创建空业务库。
   若已有数据库，程序拒绝初始化，不会覆盖单据或重置账号。
3. 双击 启动WMS.bat 或 WMS.exe。
4. 浏览器访问 http://127.0.0.1:8080/login。
5. 初始账号 admin；初始密码按 WMS_BOOTSTRAP_PASSWORD 配置，未配置时为 admin。
   请按登录后的页面提示修改初始密码。

不需要安装 Python 或联网下载依赖。手机使用需连接运行中的 WMS 服务。
本包不包含历史业务数据。旧版本升级、迁移和备份恢复需要单独处理。

系统参数页的“发布与运行状态”可查看完整制品身份、启动校验和当前暂停状态。
新制品包含 wms-release.json；启动前校验程序、覆盖文件和实际运行依赖。
构建时选择 -PauseExternalOperations 可封存暂停微信发送和设备队列的部署；
普通构建保留原有业务开关。该状态页只读，不能一键恢复真实发送或打印设备。
